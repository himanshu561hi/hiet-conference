# Nexus 2026 - Research Paper Management System

## Tagline: Research • Write • Connect • Publish

### Tech Stack
- Frontend: React 19, Vite, Tailwind CSS, React Router DOM, Framer Motion, React Hook Form, Zod, Axios, TanStack React Query.
- Backend: Node.js, Express.js, MongoDB, JWT, bcrypt, Nodemailer, Multer, Cloudinary.

### Folder Structure
- `/client` - Frontend React Application
- `/server` - Backend Express Application
- `/docs` - Project Documentation

### Scripts
**Client**
- `npm run dev` (inside client)

**Server**
- `npm run dev` (inside server) - Requires nodemon configuration in package.json
