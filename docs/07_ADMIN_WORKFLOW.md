# Admin Workflow

## Registration Status Lifecycle

- **Draft**: Team is still building the application. (Admin can view but usually ignores).
- **Submitted**: Final submission by Leader. Locked for the team. Ready for Admin Review.
- **Under Review**: Admin explicitly marks it as being reviewed.
- **Needs Correction**: Admin adds comments (e.g., "Upload clear ID card"). Form unlocks for the Leader.
- **Approved**: Final approval. Registration is successful.
- **Rejected**: Complete rejection (spam, irrelevant track, fake payment).

## Admin Capabilities
1. **Dashboard Overview**: View total teams, solo registrations, pending reviews.
2. **Team Management**: Force add/remove members, update team IDs.
3. **Registration Review**: View uploaded PDFs inline, view payment proofs, change statuses.
4. **Paper Review**: Assign tracks, view keywords and abstracts.
5. **Lock Registration**: Global platform toggle to stop new registrations or submissions.
6. **Send Email**: Manually trigger broadcast emails or targeted correction emails.
