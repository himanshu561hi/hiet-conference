# User Journey

## 1. Guest Journey
Visits Landing Page -> Reads About sections -> Explores Tracks & Timeline -> Decides to Participate -> Clicks "Register Now" -> Directed to Signup.

## 2. Leader Journey
Signs Up -> Verifies Email -> Logs In -> Lands on empty Dashboard.
Clicks "Create Team" -> Selects Solo/Team, enters Name -> Team ID Generated.
Invites members (via email or sharing Team ID).
Clicks "Registration" -> Fills Details -> Saves Draft.
Clicks "Paper Upload" -> Uploads PDF & Payment Proof.
Clicks "Final Submit" -> Receives Confirmation Email.
Monitors Admin Review status.

## 3. Member Journey
Signs Up -> Verifies Email -> Logs In.
Searches for Team ID (provided by Leader) -> Sends Join Request.
(Or clicks invite link from email).
Leader Accepts -> Member dashboard unlocks.
Can view Team Details and submitted Paper (read-only).

## 4. Admin Journey
Logs in to Admin Portal -> Views Dashboard metrics (Registrations today, Pending reviews).
Clicks "Registrations Review" -> Filters by "Submitted".
Opens a Registration -> Checks Payment Proof -> Validates PDF -> Updates status to "Approved".
Platform automatically emails the team.
